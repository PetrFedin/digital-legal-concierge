# Что готово в v19

## Telegram-бот

- Главное меню.
- Команды `/start`, `/menu`, `/status`, `/help`, `/cancel`.
- Калькулятор неустойки.
- Маршрут М1.
- Маршрут М2.
- Мое дело.
- Документы.
- Оплаты.
- Консультации.
- Сообщения юристу.
- История дела.

## Операционная часть

- Админка `/admin-ui`.
- Операторская страница `/operator`.
- Карточка дела.
- Очередь обращений.
- Юристы.
- Настройки сумм.
- Ручное подтверждение оплат.
- Ручная смена статуса.
- Экспорт CSV: дела, клиенты, оплаты, документы.

## Запуск и эксплуатация

- `./run.sh` — простой запуск.
- `./bot-control.sh` — меню управления.
- `scripts/full_check_v19.py` — полная проверка.
- `backup.sh` / `restore.sh` — резервное копирование.
- `/ready`, `/launch-check`, `/operator/status`.

## Платежи

- Fake-платежи для локального тестирования.
- YooKassa как опциональный провайдер.
- Webhook для YooKassa.
- HMAC-подпись для fake webhook.
- Ручное подтверждение в админке.

## Документы

- Загрузка файлов из Telegram.
- Сохранение в `storage/cases/<case_id>`.
- Версии документов.
- Статусы проверки.
- Список и карточка документа.
