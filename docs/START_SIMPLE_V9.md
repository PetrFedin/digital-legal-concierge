# Быстрый запуск Telegram-бота v9

## 1. Получить токен Telegram

1. Откройте Telegram.
2. Найдите `@BotFather`.
3. Выполните `/newbot`.
4. Скопируйте токен.

## 2. Локальный запуск

```bash
unzip digital-legal-concierge-telegram-bot_v9_simple_launch.zip
cd tg_ready_v9
./run.sh
```

Если `.env` создан впервые, вставьте токен в строку:

```env
BOT_TOKEN=ваш_токен_от_BotFather
```

После этого снова:

```bash
./run.sh
```

## 3. Docker-запуск

```bash
cp .env.example .env
# вставить BOT_TOKEN в .env
docker compose up --build
```

## 4. Что должно открыться

- Backend: http://localhost:8000/health
- Готовность: http://localhost:8000/ready
- Админка: http://localhost:8000/admin-ui

## 5. Проверка

```bash
python scripts/self_check.py
```

## 6. Минимальная работа после запуска

1. Открыть своего Telegram-бота.
2. Нажать `/start`.
3. Проверить меню:
   - 🏠 Главная
   - 🧮 Рассчитать неустойку
   - 📁 Мое дело
   - 📄 Документы
   - 💬 Связаться с юристом
4. Пройти расчет.
5. Перейти в М1 или М2.
6. Открыть админку и проверить карточку дела.

## 7. Что можно менять без кода

В админке и настройках можно менять:

- первый платеж М1;
- второй платеж М1;
- success fee;
- стоимость консультации;
- срок ожидания претензии;
- срок удержания слота;
- юристов;
- статусы дел через admin API.
