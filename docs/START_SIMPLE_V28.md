# START SIMPLE V28

## Запуск

```bash
unzip digital-legal-concierge-telegram-bot_v28_final_qa.zip
cd tg_ready_v28
./run.sh
```

## Первый экран

После запуска откройте:

```text
http://localhost:8000/final-qa/ui
```

Это финальный чек-лист ручной проверки перед передачей бота в эксплуатацию.

## Главные страницы

- `/final-qa/ui` — финальная ручная проверка
- `/go-live/ui` — финальный экран запуска
- `/production-center/ui` — production readiness
- `/operator` — операторский центр
- `/admin-ui` — админка
- `/ready` — техническая готовность
