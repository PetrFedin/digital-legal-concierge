# Операторский workflow v23

## Утро

1. Открыть `/operator`.
2. Проверить `/ready`.
3. Открыть `/task-center/ui`.
4. Открыть `/message-center/ui`.
5. Проверить новые документы и оплаты в `/admin-ui`.

## В течение дня

- Новое дело без юриста → назначить юриста.
- Новый документ → проверить, что он дошел до карточки.
- Новая оплата → проверить статус или подтвердить вручную.
- Новое сообщение → отметить как прочитанное после обработки.
- Ручное изменение → проверить в `/audit-center/ui`.

## Вечер

1. Экспортировать CSV при необходимости.
2. Проверить задачи с просрочкой.
3. Проверить аудит ручных операций.
4. Сделать backup, если проект уже в эксплуатации.
