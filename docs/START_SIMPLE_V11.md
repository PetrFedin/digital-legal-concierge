# Быстрый запуск Telegram-бота v11

## 1. Распаковать

```bash
unzip digital-legal-concierge-telegram-bot_v11_connected.zip
cd tg_ready_v11
```

## 2. Запустить одной командой

```bash
./run.sh
```

При первом запуске мастер спросит:

- `BOT_TOKEN` от BotFather;
- запускать ли Telegram-бота сейчас;
- запускать ли scheduler;
- публичный URL сервиса;
- платежный режим: `fake` или `yookassa`.

Для локального теста можно оставить `PAYMENT_PROVIDER=fake`.

## 3. Открыть админку

```text
http://localhost:8000/admin-ui
```

Токен администратора лежит в `.env` в поле:

```text
ADMIN_API_TOKEN=...
```

Его нужно вставить в верхнее поле админки.

## 4. Проверить готовность

```bash
./status.sh
python scripts/final_acceptance.py
```

## 5. Что должно работать

- клиент открывает Telegram-бота;
- проходит расчет неустойки;
- выбирает М1 или М2;
- загружает документы;
- видит «Мое дело»;
- оплачивает через тестовую оплату;
- администратор видит дело в панели;
- юрист может принять дело или запросить документы;
- scheduler проверяет оплаты, слоты и сроки.
