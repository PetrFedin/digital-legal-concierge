# Telegram Bot v7 — улучшения готовности к запуску

Версия v7 сфокусирована именно на Telegram-боте, а не на Cursor или разработческой демонстрации.

## Что улучшено

1. Добавлено постоянное меню Telegram:
   - 🏠 Главная
   - 🧮 Рассчитать неустойку
   - 📁 Мое дело
   - 📄 Документы
   - 💬 Связаться с юристом

2. Добавлены команды:
   - `/start` — запуск и главное меню;
   - `/menu` — главное меню;
   - `/status` — быстрый статус активного дела;
   - `/help` — помощь;
   - `/cancel` — отмена текущего ввода без удаления сохраненных данных.

3. Улучшен калькулятор:
   - понятный стартовый экран;
   - обработка «не знаю стоимость»;
   - обработка «не знаю дату»;
   - перевод в М2 при недостатке данных;
   - проверка будущей даты передачи;
   - проверка фактической даты передачи;
   - сохранение расчета в дело.

4. Исправлен путь М1:
   - после расчета клиент идет на согласие ПД;
   - документы открываются только после согласия;
   - это соответствует экрану B-007.

5. Улучшена навигация:
   - кнопки Telegram-меню работают как обычные сообщения;
   - клиент не обязан помнить команды;
   - `/status` быстро показывает номер дела, маршрут, статус и следующий шаг.

6. Улучшены документы:
   - поддержаны callback из спецификации `doc_upload_ddu`, `doc_upload_appendix`, `doc_upload_additional`;
   - сохранена поддержка универсального `doc_type:*`;
   - добавлена защита от загрузки файла без активного дела.

7. Проверка готовности:
   - `python -m compileall -q app scripts` — успешно;
   - `python scripts/e2e_smoke.py` — успешно;
   - M1 доходит до этапа доверенности;
   - M2 доходит до подтвержденной консультации.

## Запуск

```bash
cp .env.example .env
# Вставить BOT_TOKEN от BotFather
pip install -e .
python scripts/init_db.py
python -m app.main
```

В `.env` для запуска Telegram-бота должно быть:

```env
BOT_TOKEN=ваш_токен
RUN_BOT=true
RUN_SCHEDULER=true
```

Админка:

```text
http://localhost:8000/admin-ui
```
