2. Подключить домен и HTTPS для webhook.
3. Включить PostgreSQL вместо SQLite для боевого сервера.
4. Добавить авторизацию админки через логин/пароль и роли.
5. Добавить резервное копирование по расписанию.
6. Добавить журнал входов администратора и юриста.
7. Сделать полноценные шаблоны договора, доверенности, претензии и инструкций.
8. Доработать красивый UI админки, если будет реальная ежедневная эксплуатация.
