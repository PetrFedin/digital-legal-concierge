# Рабочий процесс оператора v12

## Ежедневный порядок

1. Открыть `/admin-ui`.
2. Проверить блок «Готовность».
3. Проверить очередь дел без юриста.
4. Назначить юриста вручную или через автоназначение.
5. Проверить платежи в статусах ожидания.
6. Проверить документы на проверке.
7. Запустить «Проверки», если нужно вручную прогнать scheduler.

## Основные разделы админки

- Дашборд — общая картина.
- Дела — все обращения.
- Очередь — дела без юриста.
- Оплаты — платежи и ручное подтверждение.
- Документы — загруженные клиентами файлы.
- Юристы — добавление и контроль юристов.
- Настройки — суммы, сроки, проценты.
- Уведомления — очередь сообщений.

## Быстрые действия в карточке дела

- автоназначить юриста;
- сменить статус;
- подтвердить платеж;
- посмотреть документы;
- проверить следующий шаг клиента.

## Правило безопасности

Клиент видит только простые клиентские статусы. Внутренние комментарии и технические изменения остаются внутри админки.
