# Что добавлено в v20

- Health Center: единая проверка БД, Telegram, платежей, файлов, backup, диска и scheduler.
- Diagnostic Center: технический снимок окружения.
- Recovery Center: безопасные восстановительные действия для зависших уведомлений и платежей.
- Install Wizard UI: понятный список того, что осталось настроить.
- Demo Mode: режим показа и тестирования без боевых интеграций.
- Full check v20: компиляция, БД, smoke и импорт новых модулей.

Цель v20 — не новые экраны клиента, а эксплуатационная надежность: запустить, проверить, понять состояние, восстановить типовые сбои.
