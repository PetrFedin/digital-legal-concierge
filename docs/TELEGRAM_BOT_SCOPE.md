# Telegram Bot Scope

Пакет предназначен именно для Telegram-бота, а не для разработки в Cursor.

В MVP входят:

- клиентский Telegram-бот;
- клиентский кабинет «Мое дело» внутри Telegram;
- расчет неустойки;
- M1/M2 маршруты;
- документы;
- оплаты;
- консультации;
- сообщения юристу;
- админ-панель;
- кабинетные действия юриста через API;
- scheduler и уведомления.

В MVP не входят:

- отдельный веб-кабинет клиента;
- автоматическое юридическое заключение;
- гарантии судебного результата;
- маршруты M3/M4/M5.
