# Ops Center v20

## Главные страницы

| Страница | Назначение |
|---|---|
| `/health-center/ui` | Состояние сервиса |
| `/diagnostic-center/ui` | Диагностика окружения |
| `/recovery-center/ui` | Восстановление типовых сбоев |
| `/install-wizard/ui` | Проверка настройки запуска |
| `/operator` | Операторская панель |
| `/admin-ui` | Админка |

## Восстановление

Recovery Center намеренно ограничен безопасными действиями:

- сброс зависших уведомлений из FAILED в PENDING;
- перевод ожидающих платежей в EXPIRED.

Для POST-запросов нужен заголовок `x-admin-token`.
