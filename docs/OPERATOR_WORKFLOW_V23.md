1. Открыть `/operator`.
2. Проверить `/health-center/ui`.
3. Проверить `/diagnostic-center/ui`.
4. Проверить `/notification-center/ui` — какие события кому уходят.
5. Проверить `/backup-center/ui` — есть ли папка backups и хранилище документов.
6. Открыть `/task-center/ui` — задачи.
7. Открыть `/message-center/ui` — сообщения клиентов.
8. Открыть `/audit-center/ui` — журнал действий.
9. Открыть `/admin-ui` — работа с делами, оплатами, документами.
