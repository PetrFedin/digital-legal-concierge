# Работа оператора / администратора v11

## Главный рабочий экран

Админка доступна по адресу:

```text
http://localhost:8000/admin-ui
```

## Ежедневный порядок работы

1. Открыть вкладку **Дашборд**.
2. Проверить новые и активные дела.
3. Открыть **Очередь**.
4. Для дел без юриста нажать **Автоназначить**.
5. Открыть карточку дела.
6. Проверить документы и платежи.
7. При необходимости вручную подтвердить платеж.
8. При необходимости вручную сменить статус.
9. Запустить **Проверки**, чтобы scheduler обработал напоминания и сроки.

## Настройки без кода

Во вкладке **Настройки** можно менять:

- первый платеж М1;
- второй платеж М1;
- Success Fee %;
- стоимость консультации М2;
- срок ожидания после претензии;
- время удержания слота консультации.

## Важно

Клиент не видит внутренние комментарии администратора и технические статусы. Клиент видит только упрощенный статус в разделе «Мое дело».
