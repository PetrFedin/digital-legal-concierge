# Быстрый запуск v25

```bash
unzip digital-legal-concierge-telegram-bot_v25_enterprise_ready.zip
cd tg_ready_v25
./run.sh
```

Главные страницы:

- `/operator` — операторская панель.
- `/initial-setup-wizard/ui` — первичная настройка.
- `/integration-center/ui` — интеграции.
- `/operations-center/ui` — операционный центр.
- `/monitoring-center/ui` — мониторинг.
- `/acceptance-center/ui` — приемка.

Проверка:

```bash
./acceptance.sh
```
