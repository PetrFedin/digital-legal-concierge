# Быстрый запуск v23

```bash
unzip digital-legal-concierge-telegram-bot_v23_ops_notifications_backup.zip
cd tg_ready_v23
./run.sh
```

После запуска открыть:

- http://localhost:8000/operator
- http://localhost:8000/health-center/ui
- http://localhost:8000/notification-center/ui
- http://localhost:8000/backup-center/ui
- http://localhost:8000/admin-ui

## Что добавлено в v23

- Notification Center: понятная карта уведомлений клиента, юриста и администратора.
- Backup Center: контроль резервных копий, хранилища и команд backup/restore.
- Операторская страница дополнена ссылками на новые центры.
- `/launch-check` дополнен ссылками на новые разделы.
