# Что готово в v12

## Готово для тестового запуска

- запуск одной командой `./run.sh`;
- меню управления `./bot-control.sh`;
- проверка готовности `scripts/launch_check.py`;
- Telegram-бот;
- клиентские экраны B-001—B-028 в MVP-логике;
- маршруты М1 и М2;
- документы;
- оплаты в fake-режиме;
- webhook с подписью;
- админка;
- юристский контур;
- scheduler;
- backup/restore;
- E2E M1/M2.

## Не является полностью боевым без настройки

- прием реальных платежей;
- публичный HTTPS-домен;
- финальные юридические шаблоны;
- production S3/MinIO-хранилище;
- полноценная авторизация сотрудников вместо токена API.

## Рекомендуемый следующий шаг

1. Запустить локально.
2. Пройти тестовый М1.
3. Пройти тестовый М2.
4. Проверить админку.
5. Подключить реальную платежную систему.
6. Перенести на VPS.
