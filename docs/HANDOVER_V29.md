# Передача проекта v29

## Основная команда запуска

```bash
./run.sh
```

## Меню управления

```bash
./bot-control.sh
```

## Главные URL

- `/final-handover/ui` — страница передачи проекта.
- `/final-qa/ui` — ручная приемка.
- `/go-live/ui` — финальный запуск.
- `/production-center/ui` — эксплуатационная готовность.
- `/operator` — операторская панель.
- `/admin-ui` — админка.
- `/ready` — машинная проверка готовности.

## Проверка

```bash
python scripts/full_check_v29.py
./acceptance.sh
```

## Что надо сделать владельцу перед запуском

1. Получить BOT_TOKEN у BotFather.
2. Подключить домен и HTTPS.
3. Заполнить `.env`.
4. Проверить оплату.
5. Проверить загрузку документов.
6. Пройти M1 и M2 на тестовом клиенте.
7. Проверить админку и юриста.
