# Production checklist v11

Перед боевым запуском проверить:

## Telegram

- [ ] создан бот в BotFather;
- [ ] токен вставлен в `.env`;
- [ ] `RUN_BOT=true`;
- [ ] команды `/start`, `/menu`, `/status`, `/help`, `/cancel` отображаются в Telegram.

## Админка

- [ ] `ADMIN_API_TOKEN` заменен на длинный случайный токен;
- [ ] токен не отправлен клиентам;
- [ ] доступ к серверу ограничен.

## Платежи

- [ ] локальный `fake` режим протестирован;
- [ ] для боевого запуска подключен реальный провайдер;
- [ ] webhook доступен по HTTPS;
- [ ] секрет webhook не равен dev-значению;
- [ ] ручное подтверждение платежа доступно администратору.

## Документы

- [ ] папка `storage` создается;
- [ ] документы скачиваются из Telegram;
- [ ] backup включает `legal_bot.db`, `.env` и `storage`;
- [ ] доступ к файлам не публичный.

## Проверки

```bash
python scripts/final_acceptance.py
./status.sh
```

Если оба проходят без ошибок — MVP можно показывать заказчику и тестировать на ограниченной группе.
