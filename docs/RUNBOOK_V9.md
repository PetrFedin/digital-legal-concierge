# Runbook v9 — эксплуатация

## Ежедневно

- Проверить `/admin-ui`.
- Проверить новые обращения.
- Проверить оплату и документы.
- Проверить консультации на сегодня.
- Проверить уведомления и просрочки.

## Если бот не отвечает

1. Проверить `BOT_TOKEN` в `.env`.
2. Проверить `/health`.
3. Проверить `/ready`.
4. Перезапустить:

```bash
./stop.sh
./run.sh
```

## Если не работает админка

Проверить `ADMIN_API_TOKEN` в `.env` и в поле токена на странице `/admin-ui`.

## Если платеж не подтвердился

Для MVP есть ручное подтверждение в admin API. В боевой версии нужно подключить реальную YooKassa/CloudPayments и webhook.

## Если документы не сохраняются

Проверить папку `storage/` и права на запись.
