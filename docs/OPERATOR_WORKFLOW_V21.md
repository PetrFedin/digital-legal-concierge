# Операторский процесс v21

## Утро

1. Открыть `/health-center/ui`.
2. Открыть `/task-center/ui`.
3. Сначала обработать дела без юриста.
4. Затем документы на проверке.
5. Затем ожидающие оплаты.
6. Затем сообщения и консультации.

## Настройки

Все базовые суммы и сроки менять через `/settings-ui`.

Не менять код ради суммы 30 000 / 70 000 / 10% — теперь это настройка.

## Вечер

1. Проверить `/task-center/ui`.
2. Экспортировать CSV при необходимости.
3. Сделать backup через `./backup.sh`.
