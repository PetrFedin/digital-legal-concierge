# Финальная передача Telegram-бота v19

## Что входит

- Telegram-бот по экранной логике B-001—B-028.
- Два маршрута: М1 стандартное взыскание и М2 личная консультация.
- Калькулятор неустойки.
- Личный кабинет клиента внутри Telegram: «Мое дело».
- Документы: загрузка, версии, статусы.
- Оплаты: fake/manual и опциональная YooKassa.
- Админка `/admin-ui`.
- Операторская страница `/operator`.
- Страница передачи `/handover`.
- Карта сценариев `/scenario-map-ui`.
- Scheduler для напоминаний и сроков.
- Backup/restore скрипты.
- E2E-проверки М1/М2.

## Как работать оператору

1. Запустить `./run.sh`.
2. Открыть `/handover`.
3. Проверить `/ready`.
4. Открыть `/admin-ui`.
5. Вставить `ADMIN_API_TOKEN`.
6. Создать или проверить юриста.
7. Пройти тестовый путь в Telegram.
8. Проверить дело, документы и оплату в админке.

## Что считается готовым

- Клиент может открыть Telegram-бота.
- Клиент может рассчитать неустойку.
- Клиент может выбрать М1 или М2.
- Клиент может загрузить документы.
- Клиент видит статус в «Моем деле».
- Администратор видит дело в панели.
- Юрист может получить дело и принять решение.
- Оплата может быть подтверждена вручную или через провайдера.
- Есть резервное копирование.

## Что нужно заменить перед боевым запуском

- `BOT_TOKEN` — токен реального Telegram-бота.
- `ADMIN_API_TOKEN` — длинный секрет.
- `PAYMENT_PROVIDER` — оставить `fake` для тестов или поставить `yookassa`.
- `PUBLIC_BASE_URL` — боевой домен сервера.
- Данные юрлица, тексты договоров, согласие ПД и реквизиты.

## Главная контрольная команда

```bash
python scripts/full_check_v19.py
```
