# Работа оператора v14

## Ежедневный порядок

1. Открыть `/operator`.
2. Проверить `/ready`.
3. Открыть `/admin-ui`.
4. Проверить новые дела.
5. Назначить юриста, если дело в очереди.
6. Проверить оплаты.
7. Проверить документы.
8. Проверить уведомления.

## Что делать, если клиент завис

- Нет документов → открыть дело → проверить статус → написать клиенту через Telegram/комментарий.
- Нет оплаты → открыть платеж → отправить напоминание или подтвердить вручную, если деньги пришли.
- Нет юриста → нажать автоназначение или назначить вручную.
- Сложный кейс → перевести в М2.

## Что делать, если платеж не прошел

1. Открыть дело.
2. Открыть платеж.
3. Проверить статус у провайдера.
4. Если деньги пришли — нажать ручное подтверждение.
5. Если не пришли — оставить статус ожидания или выставить новый платеж.

## Что делать, если бот не отвечает

```bash
./status.sh
./logs.sh
./bot-control.sh
```

Если порт занят или токен неправильный, `launch_check` покажет причину.
