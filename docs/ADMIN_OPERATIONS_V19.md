# Работа администратора v19

## Ежедневный цикл

1. Открыть `/operator`.
2. Проверить готовность сервиса.
3. Открыть `/admin-ui`.
4. Посмотреть очередь новых дел.
5. Назначить юриста.
6. Проверить документы.
7. Проверить оплаты.
8. Запустить ручные проверки scheduler при необходимости.
9. Экспортировать CSV при необходимости.

## Главное в админке

- Дашборд — общее состояние.
- Дела — все карточки.
- Очередь — дела без юриста.
- Оплаты — контроль платежей.
- Документы — контроль загрузок.
- Юристы — создание и управление юристами.
- Настройки — суммы, сроки, тексты.

## Не менять без причины

- Статусы закрытых дел.
- Историю платежей.
- Документы с принятым статусом.

Если нужно ручное исправление — делать через карточку дела, с комментарием. Не лечим базу отверткой, есть панель.
