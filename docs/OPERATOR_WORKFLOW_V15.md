# Работа оператора v19

## Каждый день

1. Открыть `/operator`.
2. Проверить `/ready`.
3. Открыть `/admin-ui`.
4. Проверить очередь дел без юриста.
5. Назначить юристов.
6. Проверить ожидающие оплаты.
7. Проверить документы на проверке.
8. Проверить консультации.

## Новое обращение

1. Клиент проходит Telegram-бота.
2. Дело появляется в админке.
3. Если юрист не назначен — нажать «Автоназначить».
4. Если клиент загрузил документы — юрист проверяет.
5. Если нужна оплата — оператор контролирует статус оплаты.

## Платежи

- Если подключен провайдер, статус приходит через webhook.
- Если платеж нужно подтвердить вручную, открыть карточку дела и нажать «Подтвердить».

## Документы

- Клиент загружает файлы через Telegram.
- Юрист видит документы в карточке.
- При плохом качестве документа юрист просит новую версию.

## Резервное копирование

```bash
./backup.sh
```

## Восстановление

```bash
./restore.sh backups/<file>.tar.gz
```
