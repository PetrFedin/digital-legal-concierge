# Финальный чек-лист v19

Перед запуском убедиться:

- [ ] `.env` заполнен.
- [ ] `BOT_TOKEN` реальный.
- [ ] `RUN_BOT=true`.
- [ ] `ADMIN_API_TOKEN` заменен.
- [ ] `ADMIN_PASSWORD` задан.
- [ ] `PAYMENT_WEBHOOK_SECRET` заменен.
- [ ] `PUBLIC_BASE_URL` указывает на HTTPS-домен.
- [ ] Создан минимум один юрист.
- [ ] Проверены суммы М1/М2.
- [ ] Проверен расчет.
- [ ] Проверена загрузка документа.
- [ ] Проверена оплата.
- [ ] Проверен маршрут М2.
- [ ] Проверен перевод М2 → М1.
- [ ] Проверен CSV-экспорт.
- [ ] Проверен backup.

Команды:

```bash
python scripts/preflight_v19.py
python scripts/full_check_v19.py
./backup.sh
```
