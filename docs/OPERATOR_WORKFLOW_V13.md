# Работа оператора v13

## Ежедневный порядок

1. Открыть `/operator` и проверить готовность.
2. Открыть `/admin-ui`.
3. Проверить новые дела и очередь.
4. Назначить юриста вручную или через автоназначение.
5. Проверить документы и оплаты.
6. Запустить scheduler run-once при необходимости.
7. Сделать backup перед массовыми изменениями.

## Клиентский маршрут М1

Расчет → согласие ПД → документы → проверка юристом → договор → первый платеж → доверенность → претензия → 30 дней → суд → второй платеж → исполнение → success fee → закрытие.

## Клиентский маршрут М2

Связь с юристом → описание ситуации → документы при наличии → слот → оплата консультации → консультация → решение юриста → перевод в М1 или закрытие.

## Что можно менять без разработчика

- первый платеж М1;
- второй платеж М1;
- success fee;
- стоимость консультации;
- сроки ожидания;
- тексты и уведомления, если они вынесены в настройки;
- юристов и лимиты нагрузки.

## Что нельзя делать без понимания последствий

- вручную менять статус дела без комментария;
- подтверждать платеж без фактической сверки;
- удалять документы;
- менять токены и webhook без проверки `/ready`.
