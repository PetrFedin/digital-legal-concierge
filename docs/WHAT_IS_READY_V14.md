# Что готово в v14

## Готово

- Telegram-бот с меню: Главная, Расчет, Мое дело, Документы, Связаться с юристом.
- Основные команды: `/start`, `/menu`, `/status`, `/help`, `/cancel`.
- Маршрут М1: расчет → согласие ПД → документы → проверка → договор → платеж → доверенность → претензия → суд → исполнение → закрытие.
- Маршрут М2: описание ситуации → документы при наличии → слот → оплата → консультация → перевод в М1 или закрытие.
- Калькулятор неустойки.
- Загрузка документов из Telegram в локальное хранилище.
- Fake-платежи для тестового цикла.
- Опциональная интеграция YooKassa для реальных платежей.
- Webhook платежей.
- Админка `/admin-ui`.
- Операторская страница `/operator`.
- Ручное подтверждение платежей.
- Ручная смена статусов.
- Настройки сумм и процентов без изменения кода.
- Scheduler.
- Backup / restore.
- E2E-проверки M1 и M2.

## Что остается под конкретный боевой контур

- Подставить настоящий `BOT_TOKEN`.
- Подставить настоящий домен в `PUBLIC_BASE_URL`.
- Подключить YooKassa или оставить fake для тестов.
- Настроить HTTPS/reverse proxy на сервере.
- Проверить юридические тексты, договоры и согласие ПД.
- Проверить реальные реквизиты и тарифы.

python scripts/full_check_v14.py
