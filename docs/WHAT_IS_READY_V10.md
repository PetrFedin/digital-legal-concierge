# Что готово в v10

## Готово

- Telegram-бот с меню.
- B-001—B-028 на уровне MVP-сценариев.
- M1 / M2 маршруты.
- Калькулятор неустойки.
- «Мое дело».
- Документы и версии.
- Тестовая оплата через браузер.
- Webhook оплаты с HMAC для API-вызова.
- Админка `/admin-ui`.
- API администратора и юриста.
- Scheduler.
- Проверки готовности.
- Backup / restore.
- Простые scripts для запуска и эксплуатации.

## Что требует реальных ключей

- `BOT_TOKEN` — от BotFather.
- YooKassa / CloudPayments — для реальной оплаты.
- Публичный HTTPS URL — для production webhook.

## Что осталось на production после v10

- Подключить реальный платежный провайдер.
- Включить HTTPS на сервере.
- Настроить домен.
- Заменить dev-админку на защищенную авторизацию.
- Настроить регулярный backup на внешнее хранилище.
