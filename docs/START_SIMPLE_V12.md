# Быстрый запуск v12

## 1. Распаковать проект

```bash
unzip digital-legal-concierge-telegram-bot_v12_launch_ready.zip
cd tg_ready_v12
```

## 2. Запустить одной командой

```bash
./run.sh
```

При первом запуске мастер попросит:

- `BOT_TOKEN` от BotFather;
- включать ли Telegram-бота сейчас;
- включать ли фоновые задачи;
- платежный режим `fake` или `yookassa`.

Для теста можно оставить `PAYMENT_PROVIDER=fake`.

## 3. Открыть админку

```text
http://localhost:8000/admin-ui
```

Токен администратора находится в `.env` в поле `ADMIN_API_TOKEN`.

## 4. Проверить готовность

```bash
./bot-control.sh check
```

Или в браузере:

```text
http://localhost:8000/ready
http://localhost:8000/launch-check
```

## 5. Управление без командной магии

```bash
./bot-control.sh
```

Откроется меню:

1. первый запуск / настройка `.env`;
2. проверка готовности;
3. инициализация базы;
4. запуск сервиса;
5. финальная приемка;
6. backup;
7. статус.

## Что работает

- Telegram-бот с меню;
- маршруты М1 / М2;
- калькулятор;
- документы;
- оплаты в тестовом режиме;
- админка;
- рабочий контур юриста;
- история и статусы;
- scheduler;
- E2E-проверки.

## Что обязательно заменить перед реальными деньгами

- `PAYMENT_PROVIDER=fake` заменить на реального провайдера;
- заполнить платежные ключи;
- проверить webhook на публичном домене;
- заменить тестовые тексты договора/согласий на финальные юридические версии.
