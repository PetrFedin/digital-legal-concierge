# Карта репозитория

## app/bot
Telegram-интерфейс: меню, калькулятор, документы, оплаты, консультация, мое дело.

## app/domain
Бизнес-логика: M1/M2, калькулятор, документы, оплаты, консультации, уведомления, назначение юриста.

## app/admin
Backend-функции админ-панели: очередь, настройки, юристы, дашборд.

## app/lawyer
Сервисы рабочего места юриста: решения, проверка документов, консультации.

## app/api
HTTP API: админка, юрист, webhooks оплат, runtime-проверки.

## app/system
Редактируемые настройки: суммы, проценты, сроки.

## scripts
Инициализация БД, smoke-test, запуск scheduler.

## content
YAML-настройки для будущего переноса текстов и тарифов.
