# Операторский workflow v24

1. Открыть `/operator`.
2. Проверить `/ready` и `/launch-check`.
3. Проверить настройки `/settings-ui`.
4. Проверить задачи `/task-center/ui`.
5. Использовать `/search-center/ui` для поиска дела, клиента, платежа, документа или сообщения.
6. Открыть дело в `/admin-ui`.
7. Назначить юриста, проверить документы, оплату и статус.
8. Контролировать уведомления через `/notification-center/ui`.
9. Контролировать резервные копии через `/backup-center/ui`.

Search Center нужен администратору, чтобы быстро найти обращение без переходов по десятку экранов. В MVP это простая встроенная функция, без отдельного Meilisearch.
