# Работа оператора / администратора

## Ежедневный цикл

1. Открыть админку: `http://localhost:8000/admin-ui`.
2. Проверить новые обращения.
3. Назначить юриста, если система не назначила автоматически.
4. Проверить документы на проблемных делах.
5. Проверить ожидающие оплаты.
6. Проверить консультации на сегодня.
7. Проверить просрочки и срок 30 дней после претензии.

## Клиентский путь М1

Расчет → согласие ПД → документы → проверка юристом → договор → первый платеж → доверенность → претензия → 30 дней → суд → второй платеж → исполнение → success fee → закрытие.

## Клиентский путь М2

Связаться с юристом → описание ситуации → документы при наличии → слот → оплата → консультация → решение юриста → перевод в М1 или закрытие.

## Что нельзя делать вручную без причины

- Переводить дело в договор без проверки юриста.
- Открывать доверенность без подтверждения первого платежа.
- Подтверждать консультацию без оплаты.
- Показывать клиенту внутренние комментарии CRM.

## Быстрые команды

```bash
./status.sh      # состояние сервиса
./logs.sh        # логи Docker
./backup.sh      # backup базы и документов
./stop.sh        # остановка
```
