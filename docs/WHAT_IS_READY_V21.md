# Что готово в v21

## Добавлено в v21

- Task Center: отдельная страница операционных задач.
- Настройки UI: редактирование ключевых сумм и сроков из браузера.
- Обновлены `/operator`, `/launch-check`, `/ready`.
- Добавлен `full_check_v21.py`.

## Что закрывает Task Center

- дела без юриста;
- документы на проверке;
- ожидающие оплаты;
- назначенные консультации;
- непрочитанные сообщения;
- новые дела.

## Что закрывает Settings UI

- первый платеж М1;
- второй платеж М1;
- success fee;
- стоимость консультации М2;
- ожидание после претензии;
- удержание слота консультации.

## Что осталось следующим приоритетом

1. Полноценная форма карточки дела в админке с редактированием всех полей.
2. Боевой платежный провайдер и сверка платежей.
3. Более строгая безопасность: сессии, 2FA, revoke, IP allowlist.
4. S3/MinIO-хранилище и резервирование файлов.
