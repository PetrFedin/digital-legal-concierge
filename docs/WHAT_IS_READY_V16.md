# Что готово в v19

Готов Telegram-бот по двум маршрутам М1/М2 согласно спецификациям:

- главное меню Telegram;
- калькулятор неустойки;
- переходы «не знаю стоимость/дату» в М2;
- согласие ПД перед документами по М1;
- документы, версии, статусы;
- «Мое дело» как Telegram-кабинет;
- платежи fake + опционально YooKassa;
- webhook и ручное подтверждение оплат;
- консультация М2: описание, документы, слот, оплата, назначение;
- админка `/admin-ui`;
- операторская страница `/operator`;
- карта сценариев `/scenario-map-ui`;
- эксплуатационная инструкция `/ops-guide`;
- CSV-экспорт;
- backup/restore;
- E2E-проверки.

Главное улучшение v19: проект стал понятнее для запуска и эксплуатации — добавлены карта сценариев B-001—B-028 и единая страница оператора.
