DIGITAL LEGAL CONCIERGE — ОБНОВЛЕНИЕ ПРАВ v2

Что добавляется:
- несколько администраторов;
- несколько суперадминистраторов;
- несколько юристов;
- совмещение прав: один пользователь может быть юристом и администратором одновременно;
- управление активностью и паролями;
- автоматическое создание/активация записи в реестре юристов при назначении права «Юрист»;
- автоматическое отключение записи юриста при снятии этого права.

Как установить:
1. Поместите папку admin_roles_update внутрь папки проекта рядом с START_BOT.command.
2. Дважды нажмите APPLY_ADMIN_ROLES.command.
3. После запуска откройте http://localhost:8000/login
4. Затем откройте http://localhost:8000/access/ui

Первый пользователь:
Логин: admin
Пароль: значение ADMIN_PASSWORD из .env

Права независимы и назначаются флажками:
- Администратор
- Суперадминистратор
- Юрист

Пример допустимого набора:
Юрист + Администратор

Суперадминистратор автоматически имеет административный доступ.

Обновление сохраняет .env, токен Telegram, базу дел, документы и файлы storage.
Перед заменой программных файлов создаётся резервная копия в backups/.
